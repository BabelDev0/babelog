---
title: Fruscìo
layout: ../../layouts/Poem.astro
---

dentro ho moltitudini
fuori ho pietra

mentre le api danzano
io accumulo secoli

nessuno abita un sasso
nessuno chiede cosa sogna

eppure nelle mie viscere
strati, pressioni, ere

le api mi sorvolano
si posano, fugaci

un giorno crollerò

veloce, rumorosa, nell’aria

le api osserveranno
giusto il tempo del fragore

poi tornerà il loro fruscìo
